## 人魚村、奈落與竹取村

### 人魚村說要介紹人

不是先去刷人氣。按以下順序補齊：

1. 先讓孫市完成城堡的普通潛水改造。
2. 到金太郎村西北方的兵具屋之島附近，下潛找左源內庵，交談取得**源內之杖**。
3. 帶杖到啟程村西方海底的人魚村，與入口人物交談；左源內的引薦是進村前置。
4. 用金丹救治仍有氣息的人魚，再調查最深房間的人魚身旁，取得**人魚之淚**。只救人、不調查，仍可能沒拿到道具。
5. 將風神、雷神編入外出隊伍，帶淚珠回左源內庵完成**深海改造**。

這幾段靠城堡走海路、潛海，不是靠陸上橋梁連接；普通潛水和深海改造是兩個階段。前置依據見[左源內原文校閱對話](../translations/genai-deep-sea-upgrade.draft.zh-Hant.json)，入口見主攻略[海底交通核對](README.md#chapter-7)。

### 改造好了，如何救閻魔、去竹取？

1. 在[海底入口分圖](images/world-map-undersea-zh-Hant.png)找**奈落洞窟（圖 63／E3）**：入口是鬼島東北方海底裂縫，不必先登上鬼島。
2. 一直下潛到底層，再步行探索。破牢前補血，**隊伍目前生命合計至少 500**；最大生命值相加達標不算。
3. 救出閻魔後，若仍困在洞底，繼續與他交談、看完救援事件，直到能搭城離開。
4. 搭城走地下水道，選**南側、通竹取地區的支路**；北支路回冬雪地區。附件稱南支路為「東南／右下」，是同一行程的方向提示，不是逐格路線。
5. 從南出口浮上湖面，找開闊處停城。上岸向北到麻雀旅館七號店，再向西找竹取村。

奈落到竹取走的是地下水道，不用找跨海的橋。附件「飛到寢太郎村左側，往南下海」只保留為大區域出發提示，**不當作已驗證的最短直達路線**；入口仍以分圖及裂縫為準。竹取村若已在飛燕清單中，重訪時直接飛村，不必每次繞七號店。

## 八片水晶與重返月之宮殿

### 海底看到白光，城卻降不下去

若正在找**十六夜水晶**，先確認位於避魔仙人庵東南、吊橋附近的海底，並在海底使用月之鏡。讓城對準光點後選**調查**，不是把光點當成需要登陸的村落入口。沒有取得時先微調位置、再次調查，再查道具欄。

不要只靠光的顏色認定是哪片水晶，也不要把月之鏡和尋勇氣裝備用的勇氣之鏡混用。缺哪片就查[八片水晶總表](README.md#crystals)，不是去過八個地方就算收齊。

### 已拿滿月水晶／八片已齊，下一步？

**三途川小屋取滿月 → 核對八片 → 月宮地下找女性 → 取得鳳凰笛 → 豐饒村重鑄勇氣之劍 → 回三途川呼叫鳳凰渡河。**

三途川此時沒有要找的橋；還沒取得鳳凰就先回收水晶，不要沿河岸反覆找路。重鑄及終盤事件前留獨立存檔、補完想做的支線，詳見[第九章](README.md#chapter-9)。

### 沒有風暴村、月之祠的飛燕目的地

| 目前可用的落點 | 接下來走法 |
| --- | --- |
| 飛燕清單已有風暴村 | 直接飛村，向西穿過五個相連的月之洞窟，出口再向西到月之宮殿 |
| 已在黃泉之塔登月後的祠附近 | 往西南找風暴村，再往村西進月之洞窟 |
| 上述落點都沒有 | 飛竹取村；若尚無竹取落點，先用七號店。從竹取村往西北進黃泉之塔，依主線完成七樓羅生門戰，從後方月之社登月 |

不要把附件曾建議的「直接飛月之祠」當成人人都有的選項。龍宮城的早期登月路線通往寧靜村一帶；本次回月宮以**黃泉之塔 → 風暴村 → 月之洞窟**這條已整理的主線為準，不用龍宮入口替代。竹取村至黃泉之塔的逐段過橋情況仍未核實，不補寫橋數或逐格方向。

## 勇氣裝備與浦島的正義裝備

- **勇氣之劍數值很低：**初取得時是生鏽狀態，不要丟棄。即使尚未重鑄，也能站在勇氣岬兩尊地藏之間使用、開路往鬼島。戰鬥暫用原本較強的武器；取得鳳凰後再到豐饒村找星夜，依指示在白砂泉完成重鑄。
- **勇氣之兜找不到：**先有人氣 90，進神仙鄉找天之仙人取天樹種子，再到海之仙人庵南方島嶼中央使用、實際拜訪七夕村。之後才到神仙鄉東方海域用勇氣之鏡尋找漂泊之島。拿種子不等於已去七夕村。
- **勇氣之鎧／沓漏拿：**鎧在大太郎庵東北海底洞窟，先潛海再用勇氣之鏡；沓是黃泉之塔寶箱，不是羅生門戰利品。四件位置見[第八章裝備表](README.md#chapter-8)。
- **乙姬提到給浦島的寶物：**普通潛水改造完成後，搭城重訪龍宮城，交談並探索原先關閉的寶物區，取得**正義魚叉（正義のモリ）及正義和服（正義の着物）**，交給浦島裝備。附件的「正義之魚叉／正義之衣」指這兩件；不另加未核實的門口方位。

## 四神刀與七夕村星之井

這是可選的能力補強，不必等四把全齊才到井前許願，也不是鳳凰或最終戰的開門條件。

| 刀 | 區域與樓層線索 | 取得動作 |
| --- | --- | --- |
| 玄武刀 | 大江山下山路 3F；由上層毒沼左上落穴進入 | 到下層右上盡頭一帶調查地面，不是普通寶箱 |
| 白虎刀 | 希望之都橋下河岸，地藏附近作辨認線索 | 調查地面；附件說「最南邊橋」，此處不把未逐格核對的橋位寫死 |
| 朱雀刀 | 雷神洞窟地下 4F | 開寶箱 |
| 青龍刀 | 奈落洞窟地下 4F，寶箱周邊 | 調查地面，不是只開附近寶箱 |

樓層與地標參考[隱藏武器資料](https://newmomotaro.hateblo.jp/entry/kakusibuki)，其中有外站示意截圖可供核對；本篇不轉載圖片，也未逐格實機驗證落點。

取得任一把後：

1. 到七夕村的星之井前，讓預定補強的角色持有該刀並使用。
2. 按對話選擇要提升的能力，確認受益角色、項目與數值再答應；不合適可重選。
3. **每把刀只能實現一個願望**，不是整套總共一次，也不能反覆用同一把刷能力。部分角色不能提高最大技力，已達上限的能力也不能再加。

限制依[星之井原文校閱對話](../translations/tanabata-star-well.draft.zh-Hant.json)。附件另稱「刀不會消失」，本次未獨立核實使用後的物品保留狀態，不以此作保證；先存檔，使用後核對道具與能力。

## 雪人與鬼之笛

### 刷很久都沒有雪人

1. **先建好自己的城。**到解放後的希望之都，找西北一帶的風鈴攤購買風鈴，原文報價 **30 兩**。
2. 飛到寢太郎村左側，往西北的大太郎庵周邊雪地找敵；不必為此跨過村內原先被寢太郎擋住的橋。
3. 下城徒步走動，停用不遇敵效果，將風鈴帶在外出隊伍身上。可交桃太郎攜帶，避免留在城中待機角色或倉庫。
4. 遇到雪人（雪だるま）時，等待索取風鈴／加入的事件並答應。只送飯糰等其他事件不代表招募已完成；繼續找下一次機會，**不是以打倒雪人為目標**。
5. 出現加入訊息後，到城中確認名單及編組。

附件後來把範圍縮到「大太郎庵門外南邊」。可把庵前雪地作搜尋起點，但本次查到的資料只確認**大太郎庵附近／雪國**，未證實南邊有更高出現率，也沒有保證幾場就能招到。

### 鬼之笛哪裡拿，是否必須？

鬼之笛（日文「鬼の笛」）是加快找敵的輔助道具，**不是雪人或黑河童的招募前置**。沒有笛子仍能徒步遇敵。

可嘗試的來源：

- 在海上使用海之仙人給的釣竿釣魚，有機會取得。
- 打倒狼、獄卒、金剛、火狼等敵人，有機會掉落；狼可在麻雀旅館二號店周邊尋找。

這些是[玩家問答資料](https://super-famicom.jp/data/si/momo/momo_04.html)記載的隨機來源，不是固定購買地點或必掉物。若目的只是招雪人，不必先花大量時間刷笛子；有笛子時也要在目標敵人出沒的區域使用，不能跨區叫出指定敵人。

| 神之里、神仙鄉 | 前者要建城及神之味噌湯，後者要海島交通及人氣 90；不要混成同一門檻，見[入口詳解](README.md#gods-entry) |
